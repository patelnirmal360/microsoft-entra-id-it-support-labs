# Microsoft Entra ID | IT Support Labs

Welcome to my hands-on Microsoft Entra ID portfolio, where I document my practical experience with Identity and Access Management (IAM), user administration, and cloud-based IT support.

This repository focuses on real-world IT Support and Service Desk scenarios, including user onboarding, group management, authentication, access control, and troubleshooting.

## About This Project

The purpose of this project is to build practical Microsoft Entra ID administration skills through hands-on exercises based on real-world IT support scenarios.

To simulate a corporate environment, I created a Microsoft Entra ID tenant named **DummyCorporation**, which serves as a fictional organisation for my practice labs.

Within this environment, I practise common IT administration tasks, such as managing employee accounts, organising departmental groups, configuring access, and troubleshooting identity-related issues.

Each lab documents the business scenario, implementation steps, verification results, challenges encountered, and key learnings.

The goal is not just to understand the concepts but to gain hands-on experience applying them to situations commonly encountered in IT Support and Service Desk roles.
